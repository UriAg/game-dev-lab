# Laboratorio de juegos web

Juego educativo: doce salas que explican cómo se hace un juego 3D en el navegador, hecho con esas mismas técnicas.

Inspirado en el análisis técnico de The Last Deploy, de midudev.

    npm install
    npm run dev      # http://localhost:4330

`npm run assets` regenera el robot y la textura con meshopt y KTX2. Requiere Chrome o Edge para WebGPU; en otros navegadores cae a WebGL 2.
